# LIB_AeroCOM
Avionics communication stacks (ARINC 429, ARINC 664, MIL‑STD‑1553B) written in C for Linux/POSIX.

**Build with CMake**  
   Configure and build:
   ```bash
   cmake -S . -B build
   cmake --build build
   ```

## Key Components
- **Comm/**: Communication protocol libraries
  - ARINC 429
  - ARINC 664
  - MIL‑STD‑1553B
